# TGClean

Telegram 关键词广告过滤模块，基于 LSPosed。

移除 Telegram 原生赞助消息，并根据自定义关键词/正则表达式过滤频道中的推广消息。

## 功能

- **赞助消息移除** — 自动拦截 Telegram 官方 sponsored messages
- **关键词过滤** — 全局关键词匹配，命中消息直接从列表移除（零占位）
- **正则匹配** — 支持正则表达式模式
- **分频道规则** — 按聊天 ID 设置独立关键词
- **Reactions 过滤** — 表情反应达到阈值时自动过滤
- **白名单** — 指定对话完全不过滤
